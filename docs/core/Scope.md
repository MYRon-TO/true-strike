# 视觉检测系统范围

## 1. 文档目的

本文定义视觉检测系统 v1 的目标、需求和版本边界。系统面向单摄像头、手动触发的工件视觉检查场景。

## 2. v1 目标

- 摄像头采集不受 GUI 和检查逻辑影响。
- GUI 持续预览摄像头的最新帧。
- 生产检查使用触发时获取的最新完整帧。
- 检查方案通过配置文件定义和选择。
- GUI 支持编辑、校验、测试和保存检查方案。
- 检查核心使用明确的输入和输出，不执行外部业务副作用。
- 同一时间最多执行一次检查。

## 3. 功能需求

### 3.1 应用状态

应用包含三个互斥状态：

- 主页；
- 编辑模式；
- 生产模式。

主页负责选择配置文件，并使用该配置进入编辑模式或生产模式。主页不加载检查方案。

返回主页时，释放当前模式加载的配置、检查方案和展示结果。

### 3.2 摄像头采集

- v1 只支持一个摄像头。
- 应用启动时初始化摄像头并开始采集。
- 摄像头跨三个应用状态持续运行。
- 应用退出时停止采集并关闭摄像头。
- 摄像头采集允许阻塞，但不得等待 GUI 或检查逻辑。
- 每次采集后，将 SDK 图像数据复制到应用拥有的内存。
- 系统只保留一个权威的最新帧入口。
- 新帧可以替换最新帧，但不得改变已被消费者持有的旧帧。

### 3.3 GUI 预览

- GUI 使用 iced 实现。
- GUI 按自身刷新节奏读取最新帧。
- GUI 允许跳过中间帧。
- GUI 不积压待显示帧。
- GUI 不直接访问摄像头。

### 3.4 检查方案

- 一份配置文件定义一份检查方案。
- 检查方案不关联工件种类。
- 系统不识别当前工件种类。
- 配置使用程序已注册的检查算子。
- 配置定义算子顺序、启用状态、参数和判定规则。
- v1 检查流程为线性流程。
- 检查算子不得执行外部业务副作用。
- 配置不得包含可执行代码或任意函数地址。

### 3.5 编辑模式

进入编辑模式时，读取主页选中的配置文件，并在内存中创建可编辑草稿。

编辑模式支持：

- 修改配置草稿；
- 校验草稿；
- 编译临时检查方案；
- 使用最新帧执行测试检查；
- 将有效草稿写回原配置文件。

每次测试检查必须基于当前草稿重新校验和编译，不要求先保存。

编辑模式不执行生产检查。测试结果必须标记为测试结果。

保存配置时：

- 草稿必须通过校验和方案构建；
- `revision` 在保存成功后递增；
- 文件必须原子替换；
- 保存失败不得修改原文件及其 `revision`。

返回主页时，释放草稿和临时检查方案。

### 3.6 生产模式

进入生产模式时：

1. 读取主页选中的配置文件；
2. 校验配置；
3. 编译不可变检查方案；
4. 将其设为当前生产方案。

生产模式只读取选中的配置文件。运行期间不自动重新读取配置。

生产检查由用户手动触发。触发时固定：

- 当前最新完整帧；
- 当前生产检查方案；
- 检查元数据。

后续发布的新帧或配置文件变化不得影响正在执行的检查。

检查运行时再次触发检查，应立即返回 `Busy`。

### 3.7 检查结果

- 检查结果必须关联检查编号、检查类型、帧编号、方案编号和方案修订号。
- GUI 只保留最近一次检查展示对象。
- 展示对象必须持有检查帧共享引用。
- 有可视化数据时，在关联检查帧上显示标记。
- 无可视化数据时，显示关联检查帧和文字结果。
- 新结果替换旧结果时，释放旧检查帧引用。

### 3.8 超时与取消

- 检查超时和取消宽限期使用应用级固定值。
- 检查超时后执行协作式取消。
- 取消期间拒绝新的检查请求。
- Worker 在宽限期内停止后，系统向 GUI 报告 `InspectionTimedOut`，并恢复为空闲状态。
- 超时检查不生成正常检查结果。
- Worker 未在宽限期内停止时，应用直接 `panic`。

## 4. 质量约束

- 摄像头只能由摄像头采集组件访问。
- 摄像头采集不等待帧消费者。
- 已发布帧和已构建检查方案保持不可变。
- GUI 线程不执行检查核心。
- 检查在独立执行环境中运行。
- 检查请求串行处理。
- 状态和副作用由边界组件管理。
- 图像处理使用显式输入和输出。

## 5. v1 错误范围

v1 处理以下业务错误：

- `Busy`；
- `NoFrame`；
- `NoPlan`；
- `InvalidMode`；
- `ConfigLoadFailed`；
- `ConfigInvalid`；
- `PlanBuildFailed`；
- `ConfigSaveFailed`；
- `InspectionFailed`；
- `InspectionTimedOut`。

v1 不实现摄像头错误处理。摄像头初始化或采集失败时直接 `panic`。

## 6. v1 范围外

v1 不包含：

- 多摄像头支持；
- 工件识别；
- 工件与检查方案的映射；
- 自动触发或批量生产检查；
- 检查流程分支或依赖图；
- 配置热重载；
- 数据库及检查结果持久化；
- 历史检查记录；
- 摄像头故障恢复；
- 无法协作取消的任务恢复；
- 旧版配置或数据兼容；
- 执行外部副作用的检查算子。

# 项目文档

## 通用约定

### 术语

- **命令**：GUI 或应用运行环境向 App Controller 发出的操作请求；
- **申请**：App Controller 向 Actor 发出的、可能被业务状态拒绝的操作请求；
- **控制请求**：应用生命周期协调方要求组件停止或关闭的请求；
- **任务**：Actor 向 Worker 提交的工作；
- **输出**：Worker 返回 Actor 的任务终止结果；
- **事件**：Actor 向 App Controller 发送的异步领域事实；
- **投影**：组件发布的可替换最新状态。

### 规范用语

- **必须、不得**：强制约束；
- **应当**：无特殊理由时必须遵守；
- **可以**：允许但不要求；
- **待定义**：仅为预留项，不构成有效约定。

### 资源与所有权术语

- **资源**：具有明确创建、持有、转移或共享以及释放边界的值、对象或外部能力；
- **持有**：组件对资源的生命周期负有释放责任，并可以在规约允许的范围内使用该资源；
- **唯一持有**：同一逻辑资源在同一时刻只有一个持有者；
- **共享持有**：多个持有者通过彼此独立的不可变共享引用使用同一对象；
- **临时持有**：资源只在一次命令、消息处理或同步调用期间存在，尚未进入已提交状态；
- **借用**：在限定调用或处理边界内临时访问资源，不取得释放责任，也不得使引用越过该边界；
- **转移**：释放责任从发送方移交给接收方；转移完成后，发送方不得再访问该值；
- **复制共享引用**：产生一个新的独立持有者，不转移或复制底层不可变对象；
- **释放引用**：当前持有者放弃自己的共享引用，不保证底层对象立即销毁；
- **销毁对象**：最后一个持有者释放后结束底层对象的物理存活期；
- **逻辑有效期**：资源可以作为当前领域状态或操作依据的期间；
- **物理存活期**：底层对象因仍被持有而实际存在的期间，可以长于逻辑有效期。

### 默认行为

除非文档另有说明：

- 未明确允许的状态转换均非法；
- 操作失败不改变状态或已提交资源；
- 系统不进行隐式重试；
- 状态和资源变化必须显式定义；
- 实现不得自行扩展未定义行为。
